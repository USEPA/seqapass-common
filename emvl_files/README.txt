The files here are provided to help new users set up files that are needed but should not be managed by git as they may differ between users.  Examples include:

Files for Eclpise and Maven
  .classpath                       <-- used by Eclipse, but should not be in repo
  .project                         <-- used by Eclipse, but should not be in repo
  .settings                        <-- used by Eclipse, but should not be in repo
  seq_formatting1.xml              <-- use to set the auto-fomatting in Eclipse
  settings.xml                     <-- helps Maven find a Java JDK

Files for git
  .gitconfig                       <-- use to set user-specific or machine-specific settings for git
